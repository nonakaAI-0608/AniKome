アニコメ v5（ニコニコ コメント保存）

起動
ZIPを展開して「起動.vbs」を実行してください。uvが必要です。
コマンドプロンプトは表示しません。起動失敗時は startup.log を確認。
v4のsettings.jsonを新しいフォルダへコピーすれば設定を引き継げます。
旧「照合する動画フォルダ」がある場合はそれを保存・参照先として採用します。

設定と操作
1. コメント取得に成功したnndownload-master直下のnndownload.pyを指定。
   requirements.txtと同じ階層のファイルです。
2. NicoConvAss.exeを指定（入手先：https://vb45wb5b.seesaa.net/#nicoconvass）。
3. 「ASS保存先・動画名の参照フォルダ」に動画のあるフォルダを指定。
   サブフォルダも照合し、ASSは各動画と同じフォルダへ同じ名前で保存します。
4. Firefoxでニコニコにログインしておきます。
5. 検索結果を複数選択し「選択した動画を一括保存」。
6. 動画との対応を確認して実行します。未一致は行のダブルクリックで指定。
   手動指定も保存・参照フォルダ内の動画に限定します。

処理
コメント取得 → XML変換 → ASS変換 → 動画と同じ名前で保存 → 作業用XML削除。
XMLだけの出力はありません。2つの出力チェックボックスは廃止しました。
既存ASSがある場合はスキップします。動画本体は変更しません。
複数の行が同じ動画を参照する場合は、重複を解消してから実行してください。
既に存在していたXMLは削除しません。この実行で作った作業用XMLだけを削除します。
失敗・キャンセル時は診断用に途中ファイルを残します。
work内にはJSONとログも残ります。不要になった古い作業フォルダは削除できます。

動画との照合
ニコニコのタイトルと動画ファイル名から「作品名＋話数」を読み取って照合します。
話数は「第1話」「第1羽」「第1R」「第一話」「#1」「Step1」「Lesson.1」「- 01」「作品名 01「…」」などに対応。
ファイル名先頭の[グループ名]・末尾の(BD 1280x720 …)は無視します。
作品名が一致しない場合は、動画のあるフォルダ名（[さ]三者三葉 → 三者三葉）でも照合します。
記号だけが違う別シーズン（？と？？など）は記号まで比べて区別します。
それでも見つからない場合は「話数のみ一致」「類似度」で推定し「推定・要確認」と表示します。
推定の行は対応を確かめて「推定を承認」を押したときだけ保存対象になります。
OVA・NCOP/NCED・映像特典・番外編・11.5話のような動画は自動照合しません（手動指定）。

リアルタイム表示
全体の何件目か、動画ファイル名、動画ID、現在の工程を表示します。
取得中はnndownloadの実際の進捗値（合計受信件数・各スレッドの件数）を表示。
コメントはまとめて受信されるため、1コメントずつではなく受信単位で更新します。
認証・準備中は件数を推測せず準備中と表示します。
レート制限やキー更新も取得側が出力する進捗・ログに反映します。
件数はスレッドごとの取得上限で、0は全件要求です。
サーバーの応答・取得単位によって指定件数を超えたり満たさない場合があります。

キャンセル
「取得・処理をキャンセル」で取得プロセスと子プロセスを停止します。
残りの動画も処理しません。保存が完了したASSは残します。
ASS変換中のキャンセルも可能です。短いファイル処理中は工程の切れ目で停止します。
停止が完了するまでウィンドウを閉じずにお待ちください。

検索順
「公式チャンネルのみ（so動画）」オン時は、表示対象を動画IDの数値の昇順にします。
例: so9 → so11 → so100。取得済みの検索結果全体に適用します。
未取得の全検索結果を先に取得する変更ではありません。
dアニメ検索は従来どおり、追加走査最大20ページです。

NicoConvAss
「ニコニコ動画コメント vpos→date変換」はオフにしてください。
このツールが一時XMLで処理します。
出力先はNicoConvAss.exeのフォルダ、または入力XMLのフォルダにしてください。
当ツールが完成ASSを動画のフォルダへ保存します。
解像度・透明度は当ツールの設定を反映し、その他はNicoConvAssの設定を使います。
今回の一時XMLの名前に対応するASSのみを取り込みます。

ドラッグ＆ドロップ
nndownload.py → 取得ツール欄
NicoConvAss.exe → 変換ツール欄
フォルダ → ASS保存先・動画名の参照フォルダ欄

検証範囲
変換・削除・既存ファイル保護・ソート・進捗通知をサンプルで検証。
実プロセスを用いたリアルタイムログ表示とキャンセルも検証。
Windowsでの実取得、プロセスツリー停止、NicoConvAss本体は利用PCで確認が必要です。
